# Pelin idea
Pelin ideana on kulkea tarinan mukana hauskassa seikkailussa. Tutkimalla ja valitsemalla eri vaihtoehtoja päätät itse tarinan suunnasta.
# Tavoite
Pelin tavoitteena on tutkia miten erivaihtoehdot johtavat erilaisiin seuraamuksiin.
# Toiminta periaate ja toiminnallisuus
Periaatteena on ekologisempi valinta -> parempi lopputulos
# Kestäväkehitys
Kestäväkehitys on tärkeää, joten sisällytin sen peliini sen mukaisesti. Jos tekee huonoja valintoja niin lopputuloskaan ei ole hyvä. Tekemällä ekologisia valintoja pelissä saa sinulle paremman kokemuksen. :)
